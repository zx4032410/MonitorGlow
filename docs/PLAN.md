# MonitorGlow 計畫

## 目標

Mac 選單列 App（Swift 原生）：螢幕同步、單色與亮度、動態燈效、音樂律動。只支援 Mac。

## 實機驗證（2026-11-25，型號 000501、27 吋、65 顆、韌體 1.9.4）

- `0x82` 讀資訊、`0x86` 單色、`0x85` 動態與音樂（各第 1 種）、`0x97` 關燈都可用；`0x87`／`0x8A`／`0x8B` 只確認可送出；線序 RGB；report 補零到 64 bytes 可用
- `0x80` 逐顆控制可用；第 1 顆在正面看的**右下**，走向右→上→左
- `0x86` 一包多段時，整條只呈現第一段的顏色（當時只試過一次）；逐顆一律走 `0x80`
- 螢幕同步：使用者確認正常；同步中約 2.5–3.6% CPU、27 MB（`top` 五次取樣，約 25 秒）
- 停送 `0x80` 後停在最後一幀，不會自動熄，所以離開同步要自己送下一個狀態

## 還沒驗證

- 螢幕同步的長時間穩定度
- 睡眠／喚醒、拔插重連、登入時啟動
- 7＋7 種燈效的外觀與命名、線控器按鍵回報 `0xF1`
- 34 吋等非 16:9 螢幕（只有推算）
