# 燈條 USB 協定筆記

適用 `1a86:fe07`。標「實機」的在型號 `000501`、韌體 1.9.4 上驗證過；其餘來自靜態分析，未實測。

## 介面

- HID usage page `0xFF00`、usage 1，收發各 64 bytes，沒有 report ID（實機）
- 同一裝置另有鍵盤介面，不使用
- 訊框超過 64 bytes 就切成多個 report，不足補零（實機）

## 訊框

```text
RB：52 42 | 總長 u8     | 序號 | action | payload | 加總 mod 256
SC：53 43 | 總長 u16 BE | 序號 | 80     | payload | 加總 mod 256   （只給螢幕同步）
```

序號範圍 1–254。分段資料每段 5 bytes：`起點, R, G, B, 終點`，1 起算、含頭含尾。

## 指令

| action | payload | 用途 | 驗證 |
|---|---|---|---|
| `80`（SC） | 分段×n | 螢幕同步，一幀一包 | 實機 |
| `82` | 無 | 讀型號、吋數、燈數、韌體 | 實機 |
| `85` | `[2, 0–6]`／`[3, 0–6]` | 內建動態／音樂效果 | 實機（各第 1 種） |
| `86` | 分段 | 整條單色 | 實機 |
| `87` | `[5–255]` | 亮度 | 只確認可送出 |
| `8A` | `[100 − 速度]` | 動態速度 | 只確認可送出 |
| `8B` | `[0–100]` | 音樂靈敏度 | 只確認可送出 |
| `97` | 無 | 關燈 | 實機 |

`82` 的回應：`[5..7]` 型號、`[8]` 吋數、`[11]` 燈數、`[21..23]` 韌體版本。

**不要送**：`81`（改寫裝置身分）、`95`（改燈數）、`93`（OpenRGB 的註解指出會永久改變裝置設定），以及任何未列出的 action。

## 觀察

- `86` 一包放多段時，整條只呈現第一段的顏色（只試過一次），逐顆控制請用 `80`
- 停送 `80` 後燈條停在最後一幀，不會自動熄滅
- 測試用的燈條第 1 顆在正面看的右下，走向右→上→左
